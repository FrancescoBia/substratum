# Contributing

We are **not accepting contributions** to Substratum at this time. Pull requests are turned off for this repository.
Issues are the way to contribute, and they're very welcome.

## Opening an issue

- **Bugs** — say what you did, what you expected and what happened instead. Include the Substratum version, how you run it (Docker, a reverse proxy, local disk or a bucket), and for capture problems the page you were saving from.
- **Ideas and feature requests** — describe the problem you're trying to solve, not only the solution you have in mind. Some things are left out on purpose (see "How it works" in the [README](README.md)), so it helps to know what's behind the request.
- **Security issues** — please don't open a public issue. Report it privately through **Report a vulnerability** on the repository's Security tab.

Anything you post in an issue — a description, a suggestion, a code snippet, a screenshot — is welcome as input, and by posting it you agree that the maintainer may use it in Substratum under any license, without owing you anything for it. If you'd rather keep a snippet under your own terms, describe the fix instead of pasting the code.
